LiveMeet is a full-stack real-time social chat and video calling platform
Built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).
The application features secure JWT authentication, real-time messaging, notifications, friend management, user search and filtering, responsive mobile-first UI, and one-to-one video calling using Stream Chat and Stream Video SDK.
The project focuses on scalable architecture, real-time communication, responsive design, and optimized frontend performance using TanStack Query.
